# Der Leak-Scan in tools/check.sh vergleicht das Repository gegen
# tools/leakscan-local.txt - eine lokale Liste von Kennzeichen der privaten
# Installation (Datenbankbenutzer, Hostnamen, Adressen), die niemals in eine
# versionierte Datei geraten duerfen.
#
# Einzelne dieser Zeichenketten sollen aber sehr wohl oeffentlich sein. Sie
# stehen hier, nicht in der lokalen Liste: eine Ausnahme dort wuerde den
# Schutz still aufweichen und niemandem auffallen. Hier ist sie versioniert,
# im Diff sichtbar und mit Begruendung.
#
# Eine Fundstelle wird nur dann durchgelassen, wenn nach dem Entfernen der
# hier genannten Zeichenketten kein verbotener Ausdruck mehr uebrig bleibt.
# Eine Zeile, die daneben noch ein echtes Kennzeichen enthaelt, faellt also
# weiterhin auf.
#
# Format: eine Zeichenkette je Zeile. # leitet einen Kommentar ein.
